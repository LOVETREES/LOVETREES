## Source de vérité du Projet 127

La source normative n'est pas un ancien prototype GitHub. L'ordre de référence est :

1. Framework 127 — Manifeste v1.0
2. Fiches canoniques des Sept Sœurs
3. contrats et schémas versionnés
4. ADR/RFC validés
5. code actuellement déployé
6. décisions produit explicites

Le Core 127 doit rester séparé de WordPress, des fournisseurs et des anciens proxies.
